# Junost Cinema — portfolio concept

An independent web-design and development portfolio concept inspired by [junost.ru](https://junost.ru/), the website of the **Юность cinema in Voronezh, Russia**. The repository name is retained for continuity; the reference venue is a cinema, not a theatre.

**Not an official cinema website. This project is not commissioned, endorsed, or approved by the cinema.**

## Status

Reference-site research completed on 2026-10-13. Design and implementation have not started; the implementation stack, deployment platform, and license remain undecided.

See the [research dossier](docs/research/2026-10-13-junost/README.md) for the venue fact sheet, observed functionality, design/accessibility audit, client-code findings, integration boundaries, and proposed redesign brief.

## Scope

- Explore an accessible, responsive cinema website experience.
- Present design decisions and working source code as portfolio evidence.
- Keep any booking, payment, or enquiry flows explicitly demonstrational until separately authorized and implemented.
